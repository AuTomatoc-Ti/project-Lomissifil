> **⚠️ TERMINOLOGY WARNING (author's clarification) — read before using this file.** The language has
> **NO tone/pitch**: vowels are not distinguished by pitch, and the language **never sounds chords**.
> The names **tonic / subdominant / dominant** ("I / IV / V") are **only a mnemonic metaphor**, borrowed
> from music theory, for three **relational vowel-colour classes**. What physically exists is:
> (a) each vowel has a **colour** (the locked bright↔dark palette, `01-phonology.md` §2), and
> (b) a suffix vowel stands in a **relational degree of contrast** to the root's last vowel —
> operational definition: **same vowel = "tonic" · the class's central vowel = "subdominant" · the
> opposite pole = "dominant"**. Never read "chord", "harmony" or "cadence" in this file as acoustics;
> they are **grammar-level labels**. Whether they ever become real harmony is the composer's choice and
> belongs to the (not started) prosody ↔ melody area.

## Goals (priority order, from `.clinerules/colang.md`)

1. Beautiful to hear — suited for music, poetry, novel.
   Specifically must work in: **epic/powerful power metal · emotionally delicate
   post-rock · resonant symphonic vocals · ethereal nostalgic folk**.
2. Neutral — may be inspired by many languages, but must not resemble any one too
   much; **avoid loanwords**.
3. Typable on an English keyboard, **no custom symbols** (letters only).
4. See goals file for the rest.

## Quick reference (LOCKED)

| Layer | Decision |
|---|---|
| Vowels (7) | `a` /ɑ/ · `ae` /æ/ · `e` /e/ · `o` /o/ · `i` /i/ · `u` /u/ · `y` /y/ |
| Diphthongs (8) | `ai au ei eu oi ou aei aeu` = nucleus {a,ae,e,o} + off-glide {i,u} |
| Hiatus (4) | `iu yu ia ya` (front-high {i,y} x extreme-back {u,a}); 2 syllables = a "leap" |
| Consonants (**16 phonemes / 19 letters**: stops = 3 phonemes `b d g`, each with a free hard realisation `[p t k]`) | `p b t d k g` · `m n ng`(/ŋ/) · `r`([ɾ]) · `l` · `f w s sh th h` · `c`(/t͡ʃ/) · `j`(/j/) — the last two were added later |
| Spelling of sounds | `w`=/v/ · `sh`=/ʃ/ · `th`=/θ/ · `v` is NOT a normal letter (see notation) · **`sh`/`ng` are ALWAYS one phoneme, and a stop after a nasal coda (`m`/`n`) is written with its hard letter: `mp np mt nt mk nk` (P6)** |
| Geminates | `ss nn ll mm rr ww` — **intervocalic only**, never word-final |
| Syllable | `(C)V(C)`; onset clusters `pr br tr dr kr gr` (any onset) + `fm fn hm hn wm wn jm jn` (VCV only); coda `m n l r s`. **`st` is NOT a cluster** — it is coda `s` + onset `t/d` (P5) |
| Stress (default) | 2nd syllable **of the root**; affixes never move it; mono = on itself; compounds keep only the LAST root's stress (**P4d — PROVISIONAL**) |
| Notation | CAPITAL = stress · doubled vowel = length · `v` = vibrato · dictionary form voiced (`b d g`) |

| V7–V9 | diphthongs & hiatus | nuclei {a,ae,e,o} + glide {i,u}; no `/j/` `/w/` phonemes; hiatus = {iu, yu, ia, ya} |
| V10 | `/æ/` spelling | keep `ae`; length = repeat last letter → `aee` |
| C1 | consonant scope | stops `p b t d k g`; sonorants; fricatives (rich-but-controlled) |
| C2 | canonical voicing | dictionary form = VOICED `b d g`. **CLARIFIED (author): the stops are 3 PHONEMES `/b d g/`**, each with a free voiceless realisation `[p t k]` — voicing is **not** a phoneme contrast, so the inventory is **16 phonemes / 19 letters**, not "19 phonemes". Written up, with the three boundary rules (R-a domain = the stops only; R-b base forms voiced-only; R-c plain text = voiced only), in `01-phonology.md` §1. ⚠️ **R-b and R-c are AMENDED by P6**: the fixed sequence **`nk`** requires the hard letter `k` inside a base/dictionary form — as a *spelling rule*, not a register choice |
| C2b | voicing vs stress | decoupled; voiceless = "hard"; unstressed hard (`k`) legal but marked/rare. It is a **phonation (voice-quality) setting** in the performance/notation register, **not** a phonological process — which is why it may be **free and unconditioned** (cf. whispering: every stop goes voiceless and no word is lost). **Proper names are exempt from C2** (author's ruling) — hence `austareus` keeps its voiceless `t`. ⚠️ **AMENDED by P6 (author's ruling 2026-10-14): the knob is blocked on the full natural class** — a stop `/b d g/` after a nasal coda `/m/` or `/n/` is **obligatorily voiceless `[p t k]`** and is spelled with the hard letter (`mp np mt nt mk nk`). The author deliberately wanted this first natural-language-style devoicing (清化) |
| C3 | `w` | `w` = /v/ (German-style); dissolves the /w/ vs /u/-off-glide clash |
| C4 | `r` | `r` = tap [ɾ]; `tr dr kr gr pr br` are stop+`/r/` CLUSTERS, not phonemes |
| P1 | syllable skeleton | `(C)V(C)` + whitelisted onset clusters |
| P2 | onset clusters | `pr br tr dr kr gr` any onset (no adjacent consonants, never word-final); `fm fn hm hn wm wn jm jn` VCV-only; `sp`/`sk` excluded; list extensible — **`st` has been REMOVED from this list: see P5** |
| P3 | coda | `m n l r s` only |
| P4 | stress default | 2nd syllable; mono = itself; overwritable in notation |
| P4c | stress basis | counted from the ROOT; affixes do not move it |
| P4d | compound stress | only the LAST root keeps stress (head-final tendency) — **PROVISIONAL, to be re-tested** |
| P5 | status of `st` | **`st` is NOT an onset cluster.** It is the ordinary sequence **coda `s` + onset `t`/`d`** (`losdo` = `los-do`). Consequences: no syllable ever *begins* with `st`; the old "VCV-only / must not touch another consonant" clause is now automatic (a word cannot start with a coda, and 3 consonants between vowels are not a legal shape); the voicing knob applies normally (`losdo` ~ `losto`); the capacity counts are unchanged, because the capacity tables already treated `st` as a coda+onset fill. Chosen over "`st` is a cluster, permanently voiceless" (which would have made `losdo` illegal, made that root knob-inert, and needed a rule exception for a single cluster) |
| P6 | `sh` / `ng` reading + the `nk` rule | **Medial `sh` and `ng` are ALWAYS a single phoneme** (`sh` = /ʃ/, `ng` = /ŋ/). Why a ruling was needed: the coda+onset readings were *also* legal but **spelled identically** (`a-sha` vs `as-ha`; `so-nga` vs `son-ga`), so one spelling covered two different phoneme sequences — i.e. real homographs — in **9.8% of the coining pool** (2,630 of 26,751; `tools/syllabify.py --stats`), which breaks `02-notation.md`'s premise that the written form is a *composer's instruction* to the singer. **Author's ruling (2026-10-14): fix the reading, plus the special rule `nk`** — a wanted **coda `n` + onset `/g/`** sequence **must** be written **`nk`** (the hard letter of the /g/ phoneme). Consequences: (a) the spelling→phoneme map is **bijective** again; (b) **`/s/` + `/h/` has no such escape**, so it is **unspellable = illegal** (1 of the 90 coda × onset combos; no suffix begins with `h`, so morphology can never need it); (c) `nk` is **not** a new cluster — it is coda `n` + onset `k`, read exactly as P5 reads `st`; (d) ⚠️ **it amends R-b / R-c**: a base/dictionary form may now contain a hard letter, but **only** inside the fixed sequence `nk`, and the homophone collision R-b guards against cannot occur (`nka` = /n.g/ vs `nga` = /ŋ/); (e) **DECIDED (author, 2026-10-14): a REAL conditioned devoicing, on the full natural class** — **any stop `/b d g/` after a nasal coda `/m/` or `/n/` is obligatorily voiceless `[p t k]`**, and **the spelling must show it**: `mb`→`mp`, `nb`→`np`, `md`→`mt`, `nd`→`nt`, `mg`→`mk`, `ng`→`nk`. Consequences: the six **nasal + stop** combinations are spelled with the hard letter and the composer's knob is **blocked in all six** (the language's first genuine phonological process); the spelling keeps predicting the sound (R-c's promise holds); and the *voiced* spellings of those six sequences are **illegal for coining** (`namgae` must be coined `namkae`). ⚠️ Data: the **pre-P6** pack contained **no `nk` spelling at all** (so the /n/+/g/ sequences P6 legalises were absent) while its `mb nb md nd mg` strings violated P6; (f) **capacity & data:** excluding the unspellable `/s/`+`/h/` fill costs **4,275 base forms (0.93%)** — the current-config figures become **453,150 / 453,226** (`05`'s P6 UPDATE) — and the pack committed on 2026-10-14 **predated P6** — it was **RE-EMITTED the same day** after the P6 rules landed: **26,484 bases, 0 duplicates, 0 P6-illegal spellings, 2,142 hard spellings** (`03-open-questions.md` §0 items 21, 24) |

| A2 | fricative asymmetry (assumed) | kept: among fricatives only `/v/` is voiced |
| R1 | bare-root shape policy | **ROOT LENGTH BY FREQUENCY (author):** **1 syllable = frequent** (`roi`), **2 syllables = the core**, **3 syllables = rare** (`argonna`). ⚠️ The five shapes below enumerate the **2-syllable core only**; the 1- and 3-syllable enumerations are **still to be written**. Shapes: `VCV(C)` / `{C}CVCV(C)` / `VCCV(C)` / `{C}CVCCV(C)` / `CVV(C)`; the word-initial `{C}C` = a single consonant or a **stop+`r` cluster** (`pr br tr dr kr gr`) — those are the ONLY clusters allowed word-initially; medial `CC` = (coda `m n l r s` + onset) or any permitted cluster (`pr br tr dr kr gr` + `fm fn hm hn wm wn jm jn`); `CVV(C)` = any **legal** VV, i.e. a diphthong (`roi`) **or** one of the 4 hiatus pairs `iu yu ia ya`; the word-final `(C)` follows a **hard** area rule — **two independent binary choices**: pick a fricative from `{f,v}` (the `/v/` member is **spelled `w`** — `v` is the vibrato mark, not a letter), and pick **either `h` or nothing** — so every base yields **exactly 2** bare roots (one from the `{f,v}` branch, one from the `{h,∅}` branch; raw form space = 4 per base, coined = 2 per base).
